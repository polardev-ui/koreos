A quick note before you start

4 GB RAM recommended · 10 GB storage minimum, 32 GB recommended. This is an early release; a virtual machine is a good place to begin. ARM64 is built for UEFI virtual machines, and is not a universal installer for ARM laptops or Chromebooks.

“AMD64” is the name of the x86-64 architecture, so the Intel and AMD downloads use the same ISO.
